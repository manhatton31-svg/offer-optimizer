# Offer Optimizer Agent

Turns any offer into high-converting X threads, email sequences, and ad copy using only Grok.

**Fast-revenue path** — minimal setup, copy-paste ready output.

## Status (Aug 7/8 2026)
- Core system prompt complete (ARC-11)
- Simple delivery interface live: `index.html` (ARC-12)
- MVP usable today: open the HTML, paste offer, copy prompt, run in Grok

## How to use
1. Open [index.html](./index.html) in any browser (or host it)
2. Paste your offer description or sales-page text
3. Click **Copy Full Prompt + Offer**
4. Paste into Grok (grok.x.ai or API) and run
5. Get the full package: snapshot + X thread + 5 emails + 3 ads + Reddit post + hooks

## MVP Scope
- Input: offer URL or description
- Output: high-converting traffic copy (X, email, ads)
- Only dependency: Grok access (API key or web)
- Later: dedicated hosting, usage billing, template library
